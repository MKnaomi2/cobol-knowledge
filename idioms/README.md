# Idioms

Practitioner patterns live here. **Zero files in v0 on purpose.**

An idiom is not a statistic. It is an attested shop practice:

- dialect (`ibm-enterprise`, `micro-focus`, `gnucobol`, `fujitsu`, …)
- platform (`z/os`, `ibm-i`, `unix`, `windows`, `tso-batch`, `cics`, `ims`, `db2`)
- years of practice (approximate)
- optional public example (GnuCOBOL, OMP labs, defect-suite) — never employer source

See `schema/idiom.schema.json` and CONTRIBUTING.md.

Until a practitioner opens a PR, this directory stays empty except this README.
