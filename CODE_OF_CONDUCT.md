# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) in spirit.

Practical rules for this ledger:

1. Attack claims, not people. COBOL practitioners are the knowledge holders.
2. Vendor criticism needs a citation. “They inflated the line count” is a claim; source it.
3. No employer-identifying war stories that could dox a person or leak a shop’s internals.
4. No pasting copyrighted manuals.
5. Reviewers say what they actually opened. “Looks good” is not a review.

Report abuse to the repository maintainer via GitHub.
